## Platform

web

## Users

Software engineering recruiters and hiring engineers, in Algeria and at international / remote companies. They arrive from a CV, LinkedIn or GitHub link, usually on a laptop, and decide in under a minute whether Omar is worth an interview. Secondary: engineers who open the repos to check the work is real.

## Product Purpose

Personal portfolio of Omar Abderrahmane Haouache, software engineer (Master in IT, software engineering, UMBB Boumerdès, 2025). It exists to get him interviews for software engineer or computer vision / AI engineer roles. Success: a recruiter opens GitHub or LinkedIn, downloads the CV, or sends a message.

## Positioning

A software engineer who ships computer vision inside real, working applications: trained models (breed classification, face recognition, parking occupancy) wired into real-time web systems (Django, React, WebSockets). Computer vision leads; full-stack engineering backs it up. Job seeker, not a freelancer: no services or offer framing.

## Operating Context

Visitors come from the CV (CV_HAOUACHE_Omar.pdf), LinkedIn (https://www.linkedin.com/in/omar-haouache-673a742b8/) and GitHub (https://github.com/HaouacheOmar). Several projects have live demos on Vercel; the rest link to GitHub. The site is in English.

## Product Principles

1. Proof over claims: show the work and link to it; no self-rated skill levels or invented stats.
2. GitHub and LinkedIn are always one click away.
3. Computer vision first, full-stack second.
4. A recruiter must understand who, what and how to reach him within the first viewport.

## Accessibility & Inclusion
